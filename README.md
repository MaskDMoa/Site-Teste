# 🌐 Site Teste

Projeto de desenvolvimento web frontend com o objetivo de fixar conhecimentos em HTML, CSS e JavaScript. Este projeto serve como um playground para testes de layouts, interatividade e estilização.

---

## 🎯 Sobre o Projeto
**Site-Teste** é um projeto prático que envolve a criação de diferentes páginas web interativas e responsivas. Ele compila experimentos de design, estruturação de conteúdo e manipulação do DOM através de scripts.

### 📝 Páginas Incluídas
O projeto é composto pelas seguintes páginas principais:
- `index.html`: A página inicial de apresentação do site.
- `historia.html`: Uma página detalhando um conteúdo narrativo ou histórico com estilos aplicados.
- `atributos.html`: Uma página interativa apresentando tabelas, listas ou atributos variados.

---

## ⚙️ Requisitos
- Um navegador web moderno (Google Chrome, Firefox, Edge, Safari, etc.)
- Opcional: Para desenvolvimento, um editor de código como Visual Studio Code.

---

## 🚀 Como Executar

Nenhuma instalação complexa é necessária! Trata-se de arquivos estáticos puros.

1. Clone o repositório para a sua máquina local:
```bash
git clone https://github.com/MaskDMoa/Site-Teste.git
```

2. Abra qualquer um dos arquivos `.html` (por exemplo, `index.html`) diretamente no seu navegador de preferência.

---

## 📁 Estrutura do Projeto
| Arquivo / Pasta | Finalidade |
|---|---|
| `index.html`, `historia.html`, `atributos.html` | Arquivos de marcação principais que definem a estrutura das páginas |
| `style.css` | Folha de estilos robusta para garantir a beleza e responsividade visual |
| `script.js` | Arquivo que contém a lógica JavaScript para as interações e manipulações das páginas |
| `img/` | Pasta contendo os recursos visuais e imagens hospedadas localmente |

---

## 💻 Tecnologias Usadas
- **HTML5** (Semântica e Estruturação)
- **CSS3** (Estilização de layouts complexos e responsividade)
- **JavaScript (ES6+)** (Comportamento e manipulação dinâmica)
